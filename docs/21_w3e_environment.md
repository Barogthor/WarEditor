# war3map.w3e - The Environment File

This is the tileset file containing all data about the tilesets of the map. The map is divided into squares called "tiles", each with 4 corners. In 3D, surfaces are defined using points, and tiles are defined by their corners (called "tilepoints").

## Map Structure

- **Tiles**: Square map divisions
- **Tilepoints**: Tile corners that define the terrain
- **Map size**: For a 256x256 map, you need 257x257 tilepoints
- **Tile textures**: Defined by each of the four tilepoints (can be mixed: half dirt, quarter grass, quarter rock)
- **Coordinate system**: First tilepoint is lower-left corner, progressing line by line horizontally

## File Format

### Header

| Field | Type | Description |
|-------|------|-------------|
| File ID | char[4] | "W3E!" |
| Format Version | int | `[0B 00 00 00]h` = version 11 |
| Main Tileset | char | Single character tileset ID |

### Tileset Configuration

| Field | Type | Description |
|-------|------|-------------|
| Custom Tilesets Flag | int | 1 = using custom, 0 = not using custom tilesets |
| Ground Tilesets Count | int | Number of ground tilesets (max 16) |
| Ground Tilesets | char[4][a] | Ground tileset IDs (e.g., "Ldrt" = Lordaeron Summer Dirt) |
| Cliff Tilesets Count | int | Number of cliff tilesets (max 16) |
| Cliff Tilesets | char[4][b] | Cliff tileset IDs (e.g., "CLdi" = Lordaeron Cliff Dirt) |

> **Note**: The cliff tile list is ignored by the World Editor, which automatically adds cliff tiles for each ground tile if a cliff version exists.

### Map Dimensions

| Field | Type | Description |
|-------|------|-------------|
| Map Width + 1 | int | Mx (e.g., 160x128 map → Mx = A1h) |
| Map Height + 1 | int | My (e.g., 160x128 map → My = 81h) |
| Center Offset X | float | Map center X offset |
| Center Offset Y | float | Map center Y offset |

#### Center Offset Calculation

The original (0,0) coordinate is at the bottom-left of the map. For easier scripting, the center is usually moved to (0,0):

```
Offset X = -1 × (Mx-1) × 128 ÷ 2
Offset Y = -1 × (My-1) × 128 ÷ 2
```

Where:
- `(Mx-1)` and `(My-1)` are actual map dimensions
- `128` is the tile size on the map
- `÷ 2` centers the coordinate system
- `-1 ×` translates the center rather than giving new coordinates

## Tilepoint Data

Each tilepoint is defined by **7 bytes**. Total blocks = `Mx × My`.

### Tilepoint Structure

| Field | Size | Description |
|-------|------|-------------|
| Ground Height | 2 bytes (short) | Height value |
| Water Level + Boundary Flag | 2 bytes (short) | Water level with embedded flag |
| Flags + Ground Texture | 1 byte | 4 bits flags + 4 bits ground texture type |
| Texture Details | 1 byte | Detail texture for bottom-left corner tile |
| Cliff Texture + Layer Height | 1 byte | 4 bits cliff texture + 4 bits layer height |

### Height Values

| Value | Height | Description |
|-------|--------|-------------|
| C000h | -16,384 | Minimum height |
| 2000h | 0 | Normal height (ground level 0) |
| 3FFFh | +16,383 | Maximum height |

### Flags (4 bits, big endian)

| Flag | Value | Description |
|------|--------|-------------|
| Boundary Flag 1 | 0x4000 | Shadow generated by World Editor on map edge |
| Ramp Flag | 0x0010 | Sets ramp between two layers |
| Blight Flag | 0x0020 | Ground appears as Undead ground |
| Water Flag | 0x0040 | Enables water |
| Boundary Flag 2 | 0x0080 | Camera bounds area (set by boundary tool) |

### Water Level

Water level uses the same format as ground height. The highest bit (bit 15) is used for boundary flag 1.

## Example Tilepoint Data

```
Raw data: 51 21 00 62 56 84 13

Ground Height: 51 21 (little endian) → 0x2151 → 8529
Water Data: 00 62 (little endian) → 0x6200
  - Boundary flag: (0x6200 & 0xC000) = 0x4000 (flag set)
  - Water level: (0x6200 & 0x3FFF) = 0x2200 → 8704
Flags + Ground: 56 → flags=5 (water + ramp), ground type=6
Texture Details: 84 → detail texture #132 (0x84)
Cliff + Layer: 13 → cliff type=1, layer=3
```

### Height Calculations

**Final Ground Height** (as shown in World Editor):
```
(ground_height - 0x2000 + (layer - 2) × 0x0200) ÷ 4
= (0x2151 - 0x2000 + 1 × 0x0200) ÷ 4
= (8529 - 8192 + 512) ÷ 4
= 212.25
```

**Water Level** (as shown in World Editor):
```
(water_level - 0x2000) ÷ 4 - 89.6
= (8704 - 8192) ÷ 4 - 89.6
= 38.4
```

Where:
- `0x2000` = ground zero level
- `-89.6` = water zero level (from water.slk: -0.7 × 128)
